# Parveen Yadav — Portfolio

Static site, no build step.

- `index.html` — the page
- `assets/js/support.js` — page runtime (loads React from unpkg)
- `assets/images/` — all images

## Deploy on Vercel
Push this folder to a GitHub repo → Import in Vercel → Framework preset: **Other**, no build command, output directory left empty (root).
